# Migrating To The 0.2 Single Async QueryLoop

AgentOS `0.2.0a1` makes a breaking reset to one native async execution kernel.
There is one `QueryLoop`, one `ProviderAttemptRunner`, and one Agent execution
entry: `await agent.run(input, stream=...)`. No compatibility aliases or
dynamic fallbacks are provided.

## API Mapping

| Old API | New API |
|---------|---------|
| `AgentBuilder.build_async()` | `AgentBuilder.build()` |
| `agent.async_run(value)` | `await agent.run(value)` |
| `agent.async_stream(value)` | `await agent.run(value, stream=True)` |
| `agent.stream(value)` | `await agent.run(value, stream=True)` |
| synchronous `agent.run(value)` | `SyncAgent(agent).run(value)` or `agentos.sync.run(agent, value)` |
| `agent.run_continuation()` | `await agent.run(LocalContinuationInput())` |
| `agent.stream_sse(...)` | `iter_sse(stream)` |
| `agent.stream_jsonl(...)` | `iter_jsonl(stream)` |
| `agent.clear_interrupt()` | Removed; cancellation state ends with the current execution lease. |
| `AsyncQueryLoop` | `QueryLoop` |

## Build And Run

`AgentBuilder.build()` now always returns the async-first Agent:

```python
agent = AgentBuilder().provider(provider).build()
outcome = await agent.run("hello")
```

There is no loop-mode selector. Web, channel, and distributed workers await the
Agent directly. A synchronous application imports the explicit adapter:

```python
from agentos.sync import SyncAgent

with SyncAgent(agent) as sync_agent:
    outcome = sync_agent.run("hello")
```

## Streaming

Both output modes consume the same `TurnStreamEvent` flow. A streaming caller
owns the returned resource and must close it:

```python
stream = await agent.run("hello", stream=True)
async with stream:
    async for event in stream:
        handle(event)
```

SSE and JSONL helpers project an existing stream; they do not start another
run:

```python
stream = await agent.run("hello", stream=True)
async with stream:
    async for chunk in iter_sse(stream):
        send(chunk)
```

Use `iter_jsonl(stream)` for newline-delimited JSON. If an application stops
serialization early, it still owns and closes the original `AgentStream`.

## Typed Inputs

Plain strings remain valid. Attachments move to `UserTurnInput`:

```python
outcome = await agent.run(
    UserTurnInput(content="inspect this", attachments=(attachment,)),
)
```

`LocalContinuationInput()` continues the current Level 1 notice without
appending a user message:

```python
outcome = await agent.run(LocalContinuationInput())
```

It is not a durable resume command. Durable runtimes must accept and validate
their own persisted command before creating an internal continuation input.

## Interrupts

`agent.interrupt()` targets only the current execution lease and returns
whether an active run was found. Cancellation state is discarded after that
lease is cleaned up, so there is no clear step and no sticky interrupt flag.

## Coordinator Boundary

The thread-based `AgentCoordinator` accepts a long-lived `SyncAgent`. Borrowed
instances remain application-owned; coordinator-created ephemeral Agents are
wrapped in owned `SyncAgent` instances and closed on detach. Distributed async
workers continue to hold the original Agent and await it directly.
